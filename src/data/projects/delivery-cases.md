## 一、某省级电网企业数据中心 — NF 防火墙双机实施

**产品**：NF 下一代防火墙 × 2（双机部署）

**交付范围**

- 两台设备的硬件信息登记与上架初始化。
- **IP 地址规划**：管理接口、业务接口与心跳接口的地址分配方案。
- **网络配置**：接口划分、路由配置。
- **策略配置**：安全域划分、访问控制策略、NAT 规则。
- **系统配置与证书管理**：设备证书配置与替换。
- 现场设备状态记录与实施收尾，并对客户方的当地管理员进行现场培训。

**我的工作**：全程参与实施，独立完成实施报告的撰写与配置记录归档。报告需覆盖两台设备的完整配置项，作为后续运维和扩维的基线依据。

## 二、某航空制造企业 — ISOP + UTS 实施

**产品**：ISOP 安全运营平台 + UTS 未知威胁检测

**交付范围**

- 两个产品的硬件信息与网络配置（接口、路由）。
- **数据源列表梳理**：把客户已有的安全设备与日志源逐项接入平台。
- **设备管理**：纳管设备的状态确认与联动配置。
- **策略配置与日志发送管理**：日志采集规则、发送策略与设备状态校验。

**与上一个项目的差别**：防火墙交付是网络层的事，规范清晰；安全运营平台的交付难点在**数据源梳理**——客户环境里设备品牌杂、日志格式不统一，得先把"谁在产生日志、日志往哪送、平台认不认这个格式"这条链路理清楚，平台才谈得上出效果。这个项目让我第一次完整理解了安全运营的落地前提。

## 三、某人寿保险公司 — 网络数据防泄漏（NDLP）测试

**产品**：NDLP 网络数据防泄漏

**测试覆盖**

- 平台管理与系统概况检查。
- **策略体系**：策略组管理、策略管理，以及策略匹配的多个维度——关键词、正则表达式、文件属性、文件加密。
- **数据面**：扫描数据浏览、策略数据浏览与查询、事件数据管理、海量数据管理。
- **配置面**：事件告警配置、系统告警配置、流量筛选管理。
- 测试结果汇总与结论输出。

**测试设计的思路**：DLP 的验证不能只测"能不能拦"，而要验证**识别维度的边界**——同一个关键词在不同文件类型里是否都能命中、正则匹配的性能损耗有多大、加密文件是否可识别。逐维度记录实际表现，比给一个"通过/不通过"更有价值。

## 四、RSAS 漏扫虚拟化版 — Azure 云平台部署手册

**产品**：RSAS 远程安全评估系统（虚拟化版）

**交付内容**：编写完整的云平台部署操作手册，把镜像从原始格式一步步处理到能跑在云上的状态：

- 镜像格式转换链：`qcow2` → `raw` → 云平台要求的镜像格式。
- 存储账户创建与镜像上传。
- 创建映像、创建虚拟机、磁盘配置。
- 网络配置：创建扫描网络接口、关联公网 IP。

**为什么要写手册**：云上部署和传统硬件交付的差别在于**每个步骤都依赖控制台操作**，没有命令行可以直接复制。手册必须把每一步的界面操作和前置条件写清楚，让没有做过的人照着也能走通。
